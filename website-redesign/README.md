# Noamany Fitness Center — Website Redesign

واجهة تسويقية عربية RTL مستقلة عن نظام الإدارة الداخلي.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يعرضه Vite. للبناء النهائي:

```bash
npm run build
```

## ملاحظات الربط

- زر «اشترك الآن» يفتح `subscribe.html`، ويحمّل كل الباقات النشطة المرتبطة بالفروع من `/api/public/portal/subscription-catalog` مع بحث وفلتر للفروع.
- زر الباقة يفتح تفاصيلها بالسعر والمدة والفروع والمميزات، وتحتها زر «تأكيد الاشتراك». بالضغط عليه تظهر طرق الدفع النشطة وأرقام التحويل والحسابات من إعدادات السيستم. يلزم التحقق من كود العضو واسمه وإتاحة الباقة لفرعه قبل الانتقال لإثبات الدفع.
- يرسل النموذج صورة الدفع (JPG/PNG/WebP حتى 5 ميجابايت) وتاريخ البداية والملاحظات إلى `/api/public/portal/online-subscriptions`، ليظهر الطلب في «اشتراكات الأونلاين» بالإدارة للمراجعة والاعتماد.
- النشر يتطلب تحديث الموقع والـ backend معًا. لا يتم تفعيل الاشتراك تلقائيًا بمجرد إرسال إثبات الدفع.
- الصور المولدة موجودة داخل `public/assets` ولا تعتمد على روابط خارجية.
- بيانات الفروع والهواتف مأخوذة من الموقع الحالي وتحتاج مراجعة نهائية قبل النشر.
