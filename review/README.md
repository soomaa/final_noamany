# مراجعات القبول

هذا المجلد يحتفظ بأدلة القبول القابلة للتدقيق، وليس بحكمٍ على اكتمال الميزة من قراءة المصدر. راجع سجل متطلبات العميل في [2026-09-09](./client-requirements-2026-09-09/INDEX.md).

لا يصبح أي صف مقبولًا قبل ربطه باختبار ناجح، ولقطات 1440×900 و390×844 عند انطباقهما، وبيانات seeded ودور المستخدم والفرع والقسم المستخدمين في الدليل.
