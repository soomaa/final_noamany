# مراجعة اكتمال API تطبيق Flutter

تاريخ المراجعة: 17 أغسطس 2026

تمت مقارنة ملف `NOAMANY_FLUTTER_COMPLETE.postman_collection.json` آليًا مع:

- `LegacyMobileController` لكل مسارات التطبيق القديم تحت `/Api/*`، بما فيها المسارات الصريحة ومسارات الـdispatcher.
- `MobileController` لكل مسارات التطبيق الحديث تحت `/api/mobile/*`.
- `UploadsController` لمسارات رفع صور البصمة والأنشطة والرسائل والمستندات.

## النتيجة

| المجموعة | الموجود في كود السيرفر | الموجود في Postman | الناقص |
| --- | ---: | ---: | ---: |
| مسارات التطبيق القديم `/Api/*` | 92 | 92 | 0 |
| مسارات التطبيق الحديث `/api/mobile/*` | 32 | 32 | 0 |
| مسارات الرفع المطلوبة | 4 | 4 | 0 |

- لا توجد مسارات تطبيق مدعومة في السيرفر وغير موجودة في Postman.
- لا توجد مسارات تطبيق مكتوبة في Postman لكن السيرفر لا يدعمها.
- يحتوي ملف Postman كاملًا على 168 request داخل 12 مجلدًا؛ العدد الإضافي يشمل سيناريوهات متعددة وواجهات إدارة الحضور.

أداة إعادة المراجعة موجودة في المشروع:

```bash
cd backend
node scripts/audit-flutter-api-coverage.js
```

ينتهي الأمر بكود خروج غير صفري إذا ظهر مسار ناقص أو غير مدعوم.
