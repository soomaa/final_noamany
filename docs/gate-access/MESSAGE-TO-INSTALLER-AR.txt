مساء الخير يا هندسة،

المطلوب تركيب كنترول ZKTeco C3-200 على بوابة HST-TP312 بحيث يكون:
- Door 1 = فتح اتجاه الدخول.
- Door 2 = فتح اتجاه الخروج.
- قارئ QR50BE للدخول على Reader 1، وقارئ QR50BE للخروج على Reader 3.
- الاتصال بين الكنترول وكمبيوتر الجيم TCP/IP محلي على Port 4370.
- الكنترول يأخذ Static IP محجوز خارج DHCP، ولا يتم فتح Port 4370 على الإنترنت.

السوفت وير اليومي هو ONE80 Gate Agent المرفق، وليس ZKAccess. ملفات Pull SDK
X64 التي أرسلها الوكيل أصبحت داخل مجلد sdk في الباكدج. ZKAccess/Device Setting
Tool يستخدم فقط وقت ضبط IP والكنترول ثم يُغلق، ولا يجوز تشغيل برنامجين متصلين
بالكنترول معًا.

قبل تحديد الـStatic IP النهائي، من فضلك شغّل الملف
Collect-One80NetworkInfo.ps1 على كمبيوتر الجيم وابعت ملف
ONE80-NETWORK-INFO.txt مع Screenshot لمدى DHCP/Reservations من الراوتر.

وقت التركيب سيكون معك:
1) باكدج ONE80 Gate Agent وبداخلها ملفات Pull SDK X64.
2) API URL وController ID.
3) Agent Token في رسالة خاصة.
4) Static IP / Subnet Mask / Gateway النهائيين.
5) Communication Password الخاص بالكنترول.

مهم: ريلايات C3 تُوصل Dry Contact فقط إلى Right Open وLeft Open في لوحة
الترنستايل، بدون إدخال 12V على مداخل الفتح. زمن نبضة الريلاي ثانية واحدة.
اختبار انقطاع الكهرباء/الحريق يجب أن يُسقط الذراع مباشرة.

يوجد ملف فني كامل داخل الباكدج باسم ENGINEER-HANDOFF-AR.pdf، ونحتاج تنفيذ
كل اختبارات القبول الموجودة في آخره قبل التسليم.
