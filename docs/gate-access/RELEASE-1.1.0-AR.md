# تجهيز ربط البوابة — 23 سبتمبر 2026

## اللي اتغيّر

- صفحة Gate Access تختار C3-200 أو INBIO160-PRO أو INBIO260-PRO بدل تثبيت C3.
- تعديل الكنترول الحالي والـIP والمنفذ والمخارج بدون إنشاء سجل أو تغيير المفتاح.
- دخول فقط، أو دخول وخروج من مخرجين، أو قارئين باتجاهين على مخرج واحد.
- تنزيل برنامج Windows وملف إعداد جاهز بدل كتابة رقم الكنترول والمفتاح يدويًا.
- إظهار فشل تحميل البيانات بدل عرضه كقائمة فارغة، والتحقق من العنوان والمنفذ.
- الاتصال online: قراءة QR → مراجعة العضوية وتسجيل الحضور → أمر الفتح.
- برنامج 1.1 لا يحذف أو يكتب مستخدمين أو بصمات أو صلاحيات داخل الكنترول.
- التثبيت يفحص API والـSDK والموديل قبل تشغيل الخدمة. يتبع تعديل إعدادات الويب.
- الأوامر والقراءات القديمة لا تفتح البوابة بعد رجوع الاتصال.

## ترتيب التشغيل

1. نشر backend وfrontend معًا من هذه النسخة، باستخدام آلية نشر المشروع المعتادة.
   لا توجد migration جديدة لهذا التغيير؛ exitDoorNo=0 يعني مخرج خروج غير مستخدم.
   الحزمة لا تتطلب reset لقاعدة البيانات ولا إعادة seed للصلاحيات القائمة.
2. فتح Gate Access وتعديل السجل القديم بالموديل وعنوان لوحة التحكم الفعليين.
   لا تفترضي أن عنوان MB20 هو عنوان InBio. ملصق HST-TP-312 هو جسم البوابة فقط.
3. تفعيل السجل إن كان معطلًا، وتنزيل ملف الإعداد بالمفتاح الحالي إن كان محفوظًا؛
   لو المفتاح غير محفوظ يُصدر مفتاح جديد مرة واحدة ويُنزّل الملف وقتها.
4. تنزيل حزمة Windows من الصفحة وفكها على كمبيوتر الجيم.
   وضع one80-gate-setup.json بجوار Install-One80GateAgent.cmd وتشغيله كمسؤول.
5. مسح QR لعضو نشط ثم منتهي/غير معروف والتأكد من الفتح/الرفض وسجل الحضور.

## ما لم يُثبت بعد

البناء والاختبارات البرمجية لا تثبت أن firmware الكنترول يدعم Pull SDK أو أنه
يرسل QR كحدث 27. لو فشل الفحص أو لم تصل القراءة، نقرأ رسالة الخطأ/موديل اللوحة
ومسار الاتصال الفعلي. لا يُستبدل ذلك بتغيير اسم الموديل في الويب أو وعد بالنجاح.
الأجهزة الموصولة PUSH/ADMS فقط تحتاج مسار تكامل مختلف. هذه النسخة ليست ذلك المسار.
الويب الجديد وحزمة Windows لم يتم نشرهما أو تشغيلهما على جهاز العميل بهذه المراجعة.

المراجع: حزمة SDK التي قدمها العميل داخل المشروع؛
https://www.zkteco.com.br/produto/pull-sdk-descontinuado/
https://www.zkteco.com.br/produto/inbio-pro-series/

## التحقق المنفذ محليًا

- backend: 20 اختبارًا ناجحًا لمسار البوابة وQR العضو، ثم build ناجح.
- frontend: 14 اختبارًا ناجحًا للإعدادات وعرض/طباعة QR، ثم build ناجح.
- PowerShell: تحليل syntax لكل السكربتات؛ اختبارات المحافظة على البيانات، هوية
  الكنترول، تحديث الإعدادات، والتقرير الخالي من الأسرار نجحت على PowerShell 7.
  تشغيل Windows PowerShell 5.1 والـDLL نفسه لم يُختبر على جهاز العميل بعد.
- مراجعة شاشة الإعداد ببيانات تجريبية محلية، والتحقق من تعطيل الحفظ لعنوان خاطئ.
- حزمة Windows: 14 ملفًا ببيان SHA-256، بينها 5 DLL بنسخة x64، بدون مفاتيح تشغيل.
- build الواجهة أعطى تحذير حجم بعض ملفات JavaScript؛ لم يمنع البناء.
