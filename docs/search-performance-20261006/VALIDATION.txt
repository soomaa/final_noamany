ONE80 search performance update — 6 October 2026

Scope
- Shared table search: local typing state, 300 ms debounce, immediate Enter.
- Reception: same typing controller, scanner normalization, shared in-flight search request; entry entitlement remains checked after selection.
- Subscription/member suggestions and refund search: scoped brief API response and cancellation.
- Cafe member input: typing isolated from the full POS; explicit search reads the current draft; stale suggestions are not selected by Enter.
- Reception class/locker suggestions: abort superseded requests and clear stale scoped results.
- Backend: identity/code-prefix lookup before substring fallback; brief search omits all history; full search ranks before loading metadata and returns only selected columns/latest attendance.
- Member lists/search: Arabic/Persian digits, formatted phones, case-normalized member codes.
- No schema or index migration added for this fix.
