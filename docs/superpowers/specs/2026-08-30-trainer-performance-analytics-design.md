# إدارة أداء المدربين وتحليل الفروع والريسبشن

## الهدف

تجميع إدارة المدربين داخل قسم واحد، مع فصل واضح بين إعدادات الإدارة، إدخال مدير الفرع للتقييم، وتقارير الأداء. يضيف النظام تحليلًا تشغيليًا للفروع والريسبشن من دون تارجت أو تقييم للريسبشن.

## النطاق المعتمد

- التارجت والتقييم والدرجات تخص المدربين فقط.
- الإدارة العليا هي الوحيدة التي تضبط بنود التقييم والتارجت الافتراضي.
- مدير الفرع يدخل درجات التقييم للمدربين داخل فرعه فقط.
- للمدرب تارجتان مستقلتان: قيمة مبيعات البرايفت، وعدد الاشتراكات.
- التارجت ثابت كقيمة افتراضية، مع السماح للإدارة بتعديل شهر محدد. لا يعدّل هذا التعديل السجل التاريخي للأشهر السابقة.
- الريسبشن يعرض له تحليل فعلي فقط: إجمالي مبيعات الشيفت، الاشتراكات المسجلة، والمبيعات الأخرى. لا توجد له تارجت أو تقييم أو درجات.

## الصفحات

### 1. مركز إدارة المدربين

صفحة دخول للقسم، تعرض قائمة المدربين وبطاقات مختصرة للشهر المختار:

- الفرع، التخصص، حالة المدرب.
- تارجت البرايفت ونسبة تحقيقه.
- تارجت الاشتراكات ونسبة تحقيقه.
- آخر تقييم وإجمالي درجاته.
- رابط لملف المدرب، التقييم، المستحقات، والإعدادات حسب الصلاحية.

### 2. إعدادات التقييم

لإدارة النظام فقط:

- إضافة بند تقييم: الاسم، الوصف الاختياري، الدرجة القصوى، الترتيب، وحالة التفعيل.
- تعطيل بند بدل حذفه عند وجود تقييمات تاريخية مرتبطة به.
- البنود المفعلة هي فقط التي تظهر لمدير الفرع عند تسجيل التقييم.

### 3. إعدادات التارجت

لإدارة النظام فقط:

- تارجت افتراضي ثابت لكل مدرب: قيمة مبيعات البرايفت وعدد الاشتراكات.
- تجاوز شهري اختياري لمدرب محدد، ويكون له شهر سريان واضح.
- عرض التارجت الفعلي للشهر: التجاوز الشهري أولًا، ثم التارجت الافتراضي إن لم يوجد تجاوز.

### 4. تقييم المدرب

لمدير الفرع والإدارة:

- اختيار الشهر والمدرب من الفرع المسموح للمستخدم به.
- عرض بنود التقييم المفعلة ودرجتها القصوى.
- إدخال درجة لكل بند وملاحظة عامة.
- حساب المجموع ونسبته تلقائيًا.
- يسمح بتعديل تقييم الشهر قبل اعتماده؛ تحفظ هوية المدخل ووقت التعديل لأغراض المراجعة.

### 5. ملف وبحث المدرب

للإدارة ومدير الفرع:

- بحث بالاسم أو الفرع أو التخصص.
- اختيار شهر/فترة لعرض الأداء.
- بيانات المدرب الأساسية.
- مبيعات البرايفت الفعلية مقابل التارجت ونسبة الإنجاز.
- عدد الاشتراكات الفعلي مقابل التارجت ونسبة الإنجاز.
- تقرير التقييم: البنود، الدرجة، الدرجة القصوى، الإجمالي والملاحظات.
- مستحقات المدرب: المكتسب، المصروف، المتبقي.

### 6. مستحقات المدربين

الصفحة الحالية تستمر كما هي مع إضافة روابط إلى ملف المدرب. تعرض الراتب الأساسي والعمولات والمستحق والمصروف والمتبقي، وتدعم تسجيل الصرف.

### 7. تحليل الفروع

للإدارة ومدير الفرع ضمن نطاق فرعه:

- فلتر فرع وفترة زمنية.
- إجمالي المبيعات، الاشتراكات المسجلة، ومبيعات البرايفت.
- قائمة أداء المدربين ونسب إنجازهم.
- ملخص أداء الريسبشن حسب الشيفت والموظف.

### 8. تحليل الريسبشن والشيفتات

للإدارة ومدير الفرع:

- فلتر فرع، موظف، شيفت، وفترة.
- إجمالي مبيعات الشيفت.
- عدد وقيمة الاشتراكات التي سجلها الموظف.
- المبيعات الأخرى التي سجلها الموظف.
- صفحة تحليل فقط، بلا تارجت أو تقييم أو درجات.

## البيانات والحسابات

### بنود التقييم

سجل إعداد مستقل لبنود التقييم. عند إنشاء تقييم شهري، تحفظ لقطة من اسم البند ودرجته القصوى داخل التقييم، حتى لا تغيّر تعديل الإعدادات نتائج الأشهر السابقة.

### التارجت

لكل مدرب إعداد افتراضي. يمكن أن يوجد تجاوز واحد لكل مدرب ولكل شهر. التارجت الفعلي للشهر هو:

1. التجاوز الشهري، إن وجد.
2. وإلا الإعداد الافتراضي للمدرب.

### الأداء

- نسبة البرايفت = قيمة مبيعات البرايفت خلال الفترة / تارجت البرايفت × 100.
- نسبة الاشتراكات = عدد الاشتراكات التي تنسب للمدرب خلال الفترة / تارجت الاشتراكات × 100.
- تعرض النسبتين منفصلتين. لا تُنشأ نسبة إجمالية موحدة من دون اعتماد أوزان رسمية من العميل.
- تقييم المدرب = مجموع درجات البنود / مجموع الدرجات القصوى × 100.

## الصلاحيات

| الدور | الصلاحيات |
|---|---|
| الإدارة | إدارة بنود التقييم، التارجت الافتراضي والتجاوزات، الاطلاع على جميع التقارير، وإدخال/تعديل تقييم المدرب عند الحاجة. |
| مدير الفرع | الاطلاع على مدربي فرعه وتحليل فرعه والريسبشن، وإدخال/تعديل تقييم مدربي فرعه فقط. لا يغير بنود التقييم أو التارجت. |
| الريسبشن | لا يصل إلى إعدادات الأداء أو التقارير الإدارية الجديدة إلا إذا مُنح صلاحية قراءة صريحة لاحقًا. |
| المدرب | يمكن الإبقاء على بوابته الحالية؛ أي إظهار ذاتي للأداء يحتاج قرارًا منفصلًا. |

## حدود النطاق

- لا يدخل الريسبشن في نظام التارجت أو التقييم ضمن هذا التغيير.
- لا يُحتسب تارجت إجمالي مركب للمدرب حتى يعتمد العميل وزنًا للمبيعات مقابل الاشتراكات.
- لا تُعدل بيانات تاريخية عند تغيير بنود التقييم أو التارجت الافتراضي.

## معايير القبول

1. لا يستطيع مدير فرع تقييم مدرب خارج فرعه.
2. لا يستطيع مدير الفرع تعديل بنود التقييم أو التارجت.
3. يؤدي تغيير تارجت شهر محدد إلى تغيير تقرير ذلك الشهر فقط.
4. يبقى تقرير التقييم القديم ثابتًا بعد تعديل بند تقييم أو درجته القصوى مستقبلًا.
5. تطابق أرقام أداء المدرب مصادرها من مبيعات البرايفت والاشتراكات المسجلة خلال نفس الفترة.
6. يعرض تقرير الريسبشن أرقام الشيفتات والموظفين من دون أي تارجت أو تقييم.
