- الاستقبال: سكان الكارت (أو كتابة الكود بالظبط) بيسجّل دخول الاشتراك الأساسي على طول، مرة واحدة في اليوم
  (السكان التاني في نفس اليوم بيقول «مسجّل دخول النهارده بالفعل» ومش بيزوّد حضور). لو العضو عنده اشتراك جاري واحد
  الشاشة بتقفل لوحدها بعد 5 ثواني وتستعد للعضو اللي بعده؛ لو عنده حصص / برايفت كمان بتفضل مفتوحة.
- تحت الصورة: آخر حضور («لم يحضر منذ … يوم»)، الإيقاف الحالي، اشتراكات اللوكر، المتبقي من InBody / سبا / حصص،
  والمبلغ المتبقي. زرار «عرض بيانات العضو وسجلاته» تحت الاسم بيفتح البيانات والسجلات تحت الاشتراكات في نفس الشاشة.
- الاشتراكات: الأساسي الجاري الأول، بعده الحصص / البرايفت الجارية، بعدها الموقوف والقادم والمنتهي. كل اشتراك عليه
  شارة (اشتراك أساسي / حصص / برايفت) والزرار بيقول بيعمل إيه (تسجيل دخول الجيم / تحضير حصة / تحضير حصة برايفت).
- الإيقاف: بداية الإيقاف + عدد الأيام، والنهاية بتتحسب لوحدها ومقفولة.
- الإيقاف (مقارنة بميتا فيت): كان بيتشال يوم بعد نهايته (العضو بيخسر يوم) → بيتشال يوم النهاية نفسه؛ بداية الإيقاف
  النهارده أو قبلها بس (البداية في المستقبل كانت بتقفل العضو من يوم الحجز)؛ باقة حصص خلصت حصصها مينفعش تتوقف؛
  اشتراك موقوف مبقاش بيمنع العضو لو عنده اشتراك تاني شغال. السكان التلقائي بيختار الاشتراك الأساسي الجاري نفسه.

  مبقتش بتضيّع أرقام السكان (كانت بتسيب آخر رقم بس «0»).

  بصلاحية جرد اللوكر نفسها.
